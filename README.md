# קטלוג קורן — קבצים להעלאה ל-GitHub Pages

תיקייה זו מכילה את **כל** מה שצריך כדי להריץ את קטלוג-הקיוסק כאתר סטטי (GitHub Pages) —
ואותו אתר בדיוק ישמש גם כדפדפן-מוצג על מסך הסמסונג בחנות.

## מה יש כאן

- **`index.html`** — קובץ יחיד, עצמאי לגמרי (HTML+CSS+JS+כל התמונות מוטמעות בפנים
  כ-base64). אין תלות בשום קובץ/ספרייה/CDN חיצוני — בדיוק כמו התבנית שרצה כ-Claude
  Artifact. זה **אותו תוכן בדיוק** שפורסם לאחרונה ל-
  `https://claude.ai/artifact/5rrpRzJ9FEvZkjLYqnEV3W`.

## איך מעלים (פעם ראשונה)

1. ליצור repository חדש וציבורי ב-GitHub (למשל `koren-electric/kiosk`).
2. להעלות את `index.html` (קובץ בודד) ל-root של ה-repo.
3. ב-Settings → Pages → Source לבחור את ה-branch הראשי (`main`), תיקיית `/ (root)`.
4. GitHub ייתן כתובת מהצורה `https://<username>.github.io/<repo-name>/` — זו הכתובת
   שגם דפדפן-הקיוסק על מסך הסמסונג יצטרך להצביע אליה.

## עדכונים עתידיים

בכל פעם שהתבנית מתעדכנת (עיצוב/פיצ'רים/מוצרים חדשים), הקובץ `index.html` בתיקייה הזו
יתעדכן בהתאם — פשוט להעלות אותו מחדש ל-GitHub (מחליף את הקיים), אין צורך בשום שינוי
נוסף בהגדרות.

## ⚠️ מגבלת-גודל לזכור

GitHub עצמו לא מגביל קובץ יחיד מתחת ל-25MB (מגבלת ה-Artifact של 16MB היא ספציפית
ל-claude.ai, לא ל-GitHub) — אבל כדאי בכל זאת לשים לב לגודל-הקובץ ככל שמצטברות תמונות-
מוצר, כדי שזמן-הטעינה בקיוסק יישאר סביר. גודל נוכחי: ~9.87MB.

## הפרדה מכוונת מ-MASTER MOUNT

זהו פרויקט **נפרד לגמרי** מאתר MASTER MOUNT (חנות-מותקני-טלוויזיה) — אין קוד/רפו/
תלות משותפת בין השניים, גם אם שניהם "אתר-סטטי-שמעלים-ידנית-ל-GitHub".
