# קטלוג קורן — קבצים להעלאה ל-GitHub Pages

תיקייה זו מכילה את **כל** מה שצריך כדי להריץ את קטלוג-הקיוסק כאתר סטטי (GitHub Pages) —
ואותו אתר בדיוק ישמש גם כדפדפן-מוצג על מסך הסמסונג בחנות.

⚠️ **הקבצים כאן נוצרים אוטומטית** ע"י `..\kiosk-admin\build.ps1` (או כפתור "בנה עכשיו"
במערכת-הניהול, `..\kiosk-admin\start-admin.bat`) — לא לערוך אותם כאן ידנית, כל עריכה
תימחק בבנייה הבאה. לעדכון-תוכן (מוצרים/קטגוריות/תמונות), ר' `..\kiosk-admin\README.md`.

## מה יש כאן

- **`index.html`** — קובץ-האתר עצמו (HTML+CSS+JS). **לא** מכיל תמונות מוטמעות — הוא
  מפנה לקבצים בתיקיות `images\`/`categories\` שלצידו (נתיבים-יחסיים).
- **`images\<קוד-דגם>\1.png, 2.png, ...`** — תמונות-מוצר, מועתקות-אוטומטית מתוך
  `..\תמונות למוצרים לפי קוד דגם\`.
- **`categories\<מזהה-קטגוריה>.png`** — תמונות-קטגוריה, מועתקות-אוטומטית מתוך
  `..\תמונות לקטגוריות קיוסק\`.

**חובה להעלות את כל שלושת-האלה יחד** (`index.html` + `images\` + `categories\`),
לא רק את ה-HTML — אחרת התמונות באתר החי יהיו שבורות.

## איך מעלים (פעם ראשונה)

1. ליצור repository חדש וציבורי ב-GitHub (למשל `koren-electric/kiosk`).
2. להעלות את **כל תוכן התיקייה הזו** (`index.html` + תיקיות `images\`/`categories\`
   על-כל-תוכנן) ל-root של ה-repo, בשמירה על אותו מבנה-תיקיות בדיוק.
3. ב-Settings → Pages → Source לבחור את ה-branch הראשי (`main`), תיקיית `/ (root)`.
4. GitHub ייתן כתובת מהצורה `https://<username>.github.io/<repo-name>/` — זו הכתובת
   שגם דפדפן-הקיוסק על מסך הסמסונג יצטרך להצביע אליה.

## עדכונים עתידיים

אחרי כל שינוי (מוצרים/קטגוריות/תמונות דרך מערכת-הניהול + "בנה עכשיו"), פשוט מעלים
מחדש את **כל** תוכן התיקייה הזו ל-GitHub (מחליף את הקיים) — אין צורך בשום שינוי נוסף
בהגדרות. אם ה-repo כבר קיים, אפשר גם "לגרור" את שלושת הפריטים (index.html + שתי
התיקיות) ישירות דרך ממשק-הווב של GitHub, זה ידרוס רק את מה שבאמת השתנה.

## ⚠️ גודל

בזכות שהתמונות הן קבצים-נפרדים (לא מוטמעות ב-HTML), `index.html` עצמו נשאר קטן-מאוד
(עשרות-KB, לא מגה-בייטים) גם כשמצטברים הרבה מוצרים — אין כאן מגבלת-גודל-מעשית בטווח
הנראה-לעין.

## הפרדה מכוונת מ-MASTER MOUNT

זהו פרויקט **נפרד לגמרי** מאתר MASTER MOUNT (חנות-מותקני-טלוויזיה) — אין קוד/רפו/
תלות משותפת בין השניים, גם אם שניהם "אתר-סטטי-שמעלים-ידנית-ל-GitHub".
